# C++ Mini Compiler

A small educational compiler pipeline for integer arithmetic expressions. It is written in standard C++17 and does not require third-party libraries.

## What it does

- **Lexing:** converts input characters into tokens.
- **Parsing:** uses recursive descent and operator precedence to build an abstract syntax tree (AST).
- **Code generation:** converts the AST into a simple stack-based bytecode.
- **Execution:** runs the bytecode on a small stack machine.
- **Error handling:** reports unexpected characters, malformed expressions, missing parentheses, and division by zero.

Supported operators: `+`, `-`, `*`, `/`, unary `+` and `-`, and parentheses. Arithmetic uses integers, so division truncates toward zero.

## Build

Requirements: a C++17 compiler and CMake 3.16+.

```bash
cmake -S . -B build
cmake --build build
```

Run:

```bash
./build/mini_compiler
```

On Windows, the executable is typically `build\\Debug\\mini_compiler.exe` with Visual Studio generators.

Show generated bytecode:

```bash
./build/mini_compiler --bytecode
```

Example:

```text
> 2 + 3 * 4
Bytecode:
0: PUSH 2
1: PUSH 3
2: PUSH 4
3: MUL
4: ADD
Result: 14
```

## Architecture

```text
Source expression
      |
      v
Lexer (tokens)
      |
      v
Recursive-descent parser
      |
      v
Abstract Syntax Tree
      |
      v
Bytecode generator
      |
      v
Stack-based virtual machine
      |
      v
Result
```

## Project layout

- `include/token.hpp` — token representation
- `include/lexer.hpp`, `src/lexer.cpp` — lexical analysis
- `include/ast.hpp` — AST node structure
- `include/parser.hpp`, `src/parser.cpp` — grammar and parser
- `include/compiler.hpp`, `src/compiler.cpp` — bytecode generation and execution
- `src/main.cpp` — command-line REPL
- `tests/manual_tests.txt` — manual test cases
